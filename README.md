# jackson-wheeler.github.io

Personal site built with [Docusaurus](https://docusaurus.io/) (classic template, TypeScript).

## Development

```bash
npm ci            # install dependencies
npm start         # local dev server at http://localhost:3000
npm run build     # production build into ./build
npm run serve     # serve the production build locally
npm run typecheck # TypeScript check
```

Deployment to GitHub Pages is not configured yet (tracked separately).
